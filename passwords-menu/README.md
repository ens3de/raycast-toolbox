# 打开密码菜单

用 Raycast 打开 macOS「密码」App 的菜单栏窗口（`com.apple.Passwords.MenuBarExtra`），并在窗口开着时加上这些快捷键：

| 页面 | 按键 | 作用 |
|---|---|---|
| 列表 | ⌘1 … ⌘9 | 打开当前可见的第 N 项 |
| 列表 | 回车（焦点在搜索框） | 打开第一项 |
| 详情 | ⌘1 / ⌘2 / ⌘3 | 复制用户名 / 密码 / 一次性验证码，并收起窗口（停在这一页，方便接着复制另一个） |
| 详情 | Esc | 返回上一页，回到首页时焦点回到搜索框 |
| 首页 | Esc | 照常关闭窗口 |

如果打开时最前面是浏览器（Safari、Chrome、Edge、Brave、Arc、Vivaldi、Opera、Ego Lite、Firefox），会读取当前标签页的域名（去掉开头的 `www.`），回到首页并把域名填进搜索框，再按回车打开第一项。读取 Safari 和 Chromium 系浏览器要用 AppleScript，首次使用时 macOS 会请求 Raycast 控制该浏览器的权限，需要允许；Firefox 读的是地址栏，不需要。新标签页、本地和内网地址（localhost、`.local`、回环和私有 IPv4）不会触发搜索。Ardia 不走这条路。

不在浏览器里时，距上次打开超过 5 分钟（`resetAfter`），再打开时会自动回到首页并聚焦搜索框。

## Ardia：先打开 iCloud 密码扩展

最前面的 App 是 Ardia（`com.ardia.browser`）时，这一轮只打开官方 iCloud 密码扩展（Chrome 网上应用店 id `pejdijmoenmkgeppbflobdenhhabjlaj`）。命令本身随后就返回，后台只留下弹窗上的按键监听。不会再点系统「密码」菜单栏，所以不会叠出「密码已锁定」那扇窗口。Raycast、Spotlight、Alfred 不算最前面的目标 App。

脚本先把 Ardia 调到前面，再向它发送 **⌘⇧\**：Command 和 Shift 按住，再按反斜杠那个键（Chrome 里记成 ⌘⇧\ 的组合），不是单独发一个 `|`。这个快捷键要你自己在 Ardia 的扩展快捷键页面绑到该扩展的「启用扩展程序」。它只是脚本里的一个常量，仓库不会改 Ardia 的偏好设置、快捷键或扩展设置。

工具栏上的扩展按钮是开关。快捷键已经发出时，同一轮不再点它，否则会把刚打开的弹窗关掉。辅助功能经常认不出这个弹窗；认不出也不改走菜单栏。

快捷键发出后，脚本再在后台留一份自己。这个弹窗经常不是 Ardia 进程新开的一扇系统窗口（可能画在页面上，或挂在辅助进程、或沿用原来的窗口），所以不再只靠「Ardia 多了一个窗口」来决定要不要处理回车。不读取、不记录、不打印账号、密码、验证码或列表文字；可以数行、看角色。

弹窗打开后不会自己填。要等你按没有修饰键的回车：

- 辅助功能看得到行（页面里的 `credentialList`，或标题 / 扩展页面能对上的弹窗大小窗口）时，点第一行。数的是行，不读内容。
- 看不见行时，这次回车改成「向下键，再回车」。没有高亮项时，扩展会把单独的回车当成关闭；向下键会高亮第一项，随后的回车由扩展填入用户名、密码和验证码。
- 已经用上下键选过别的行：回车原样交给扩展，填的是那一行。

辅助功能完全看不见列表时，还有一个短兜底，避免把网页里的回车抢走：快捷键之后大约 12 秒内，Ardia 仍在最前面，你还没打字、没按 Esc，而且焦点不在网页的文本框里，第一次回车才走上面的规则。打过字、按过 Esc、过了这段时间，或焦点在文本框里，回车还给网页。

配对用的 6 位 PIN 页（整段 6 位数字，或 PIN0…PIN5），以及已经开始按数字键的时候：不点击，不拦截回车，不发向下键，不发数字。

菜单栏窗口的 ⌘1、⌘2、⌘3 不会搬到这个弹窗上。认到的弹窗窗口关掉，或这次回车已经填过，这份监听就退出。

最前面是 Safari、别的浏览器或其他 App 时，仍然只用菜单栏流程。

正常打开不会读 Ardia 的网址。用 `--domain` 读的时候，macOS 可能会询问是否允许控制 Ardia，需要允许。`--trace` 只在标准错误打控制流（最前面的 bundle id、有没有激活、有没有发快捷键、有没有启动弹窗监听、有没有点工具栏或菜单栏），不打窗口内容。后台那份监听的标准错误是关掉的，所以它自己的那几行不会出现在这里。

## 原理

- 通过辅助功能（Accessibility）找到菜单栏图标，模拟点击打开窗口，然后把鼠标放回原处。
- 打开后，程序以 `--keys` 在后台再启动一份自己，用 CGEventTap 只拦截上表这几个键，其余按键原样放行。窗口一关它就退出（最长 1 小时），同一时间只会有一个。
- 打开某一项、复制用户名、密码或验证码，都是在对应位置模拟一次点击，用的是「密码」自己的行为（它点击即复制）。程序不读取、不记录账号或密码，也不写任何日志。只记录上次打开菜单栏窗口的时间，存在 `~/Library/Caches/open-passwords-menu.last-run`。Ardia 这一轮发快捷键，再用 `--extension-keys` 在后台等你按回车：没改过选中项时填第一项（看得到行就点第一行，否则向下键再回车）；已经用上下键选过则把回车交给扩展。打开时不自己填。不点菜单栏，不点工具栏，不启动菜单栏的 `--keys`，也不更新这个时间。配对页上的 6 位 PIN 只用来判断「这是不是配对页」，数字不保存。

## 安装

```bash
./build.sh
```

需要给 Raycast 辅助功能权限（系统设置 → 隐私与安全性 → 辅助功能）。程序从 Raycast 启动，继承 Raycast 的权限。

界面元素是按 macOS 27 上的「密码」菜单栏窗口结构写的。系统更新改了结构的话，可能需要调整。
