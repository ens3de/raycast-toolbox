# 打开密码菜单

用 Raycast 打开 macOS「密码」App 的菜单栏窗口（`com.apple.Passwords.MenuBarExtra`），并在窗口开着时加上这些快捷键：

| 页面 | 按键 | 作用 |
|---|---|---|
| 列表 | ⌘1 … ⌘9 | 打开当前可见的第 N 项 |
| 列表 | 回车（焦点在搜索框） | 打开第一项 |
| 详情 | ⌘1 / ⌘2 / ⌘3 | 复制用户名 / 密码 / 一次性验证码，并收起窗口（停在这一页，方便接着复制另一个） |
| 详情 | Esc | 返回上一页，回到首页时焦点回到搜索框 |
| 首页 | Esc | 照常关闭窗口 |

如果打开时最前面是浏览器（Safari、Chrome、Edge、Brave、Arc、Vivaldi、Opera、Ego Lite、Firefox、Ardia），会读取当前标签页的域名（去掉开头的 `www.`），回到首页并把域名填进搜索框，再按回车打开第一项。读取 Safari、Chromium 系浏览器和 Ardia 要用 AppleScript，首次使用时 macOS 会请求 Raycast 控制该浏览器的权限，需要允许；Firefox 读的是地址栏，不需要。新标签页、本地和内网地址（localhost、`.local`、回环和私有 IPv4）不会触发搜索。

不在浏览器里时，距上次打开超过 5 分钟（`resetAfter`），再打开时会自动回到首页并聚焦搜索框。

## Ardia：先打开 iCloud 密码扩展

最前面的 App 是 Ardia（`com.ardia.browser`）时，不先点菜单栏图标，而是先打开官方 iCloud 密码扩展（Chrome 网上应用店 id `pejdijmoenmkgeppbflobdenhhabjlaj`）。

脚本向 Ardia 发送 **⌘⇧\**：Command 和 Shift 按住，再按反斜杠那个键（Chrome 里记成 ⌘⇧\ 的组合），不是单独发一个 `|`。这个快捷键要你自己在 Ardia 的扩展快捷键页面绑到该扩展的「启用扩展程序」。它只是脚本里的一个常量，仓库不会改 Ardia 的偏好设置、快捷键或扩展设置。

发出快捷键后只短等一下，看有没有多出一个扩展弹窗。认弹窗只看窗口标题和角色：标题对得上 iCloud 密码，或者窗口是弹窗大小、文档地址是 `extension://` 加上上面的扩展 id；标题为空时，只有它是这段时间里唯一多出来的、弹窗大小的窗口才算。不读取、不记录、不打印账号、密码、验证码或列表内容。

- 弹窗要是配对用的 6 位 PIN 页，脚本不会按回车，也不会选任何一项，页面留在原地。
- 弹窗要是密码选择页，这一步也只负责打开。接着用扩展自己的方向键和回车选一项，由扩展把用户名、密码和验证码填进网页。菜单栏窗口的 ⌘1、⌘2、⌘3 不会搬到这个弹窗上。

快捷键没有唤起弹窗时，如果工具栏里能唯一对上已固定的 iCloud 密码按钮（标题、描述或标识里就是这个扩展），就点一下再等弹窗。请把扩展固定到工具栏，这一步才找得到；对上不止一个，或者根本不在工具栏里，就不当作找到了。按钮也失败时，退回上面的菜单栏流程，并按 Ardia 当前标签页的域名搜索。

最前面是 Safari、别的浏览器或其他 App 时，仍然只用菜单栏流程。

第一次用 AppleScript 读取 Ardia 的当前网址时，macOS 可能会询问是否允许控制 Ardia，需要允许。扩展弹窗已经打开时不会去读网址。

## 原理

- 通过辅助功能（Accessibility）找到菜单栏图标，模拟点击打开窗口，然后把鼠标放回原处。
- 打开后，程序以 `--keys` 在后台再启动一份自己，用 CGEventTap 只拦截上表这几个键，其余按键原样放行。窗口一关它就退出（最长 1 小时），同一时间只会有一个。
- 打开某一项、复制用户名、密码或验证码，都是在对应位置模拟一次点击，用的是「密码」自己的行为（它点击即复制）。程序不读取、不记录账号或密码，也不写任何日志。只记录上次打开菜单栏窗口的时间，存在 `~/Library/Caches/open-passwords-menu.last-run`。Ardia 里扩展弹窗打开成功时，不启动按键拦截，也不更新这个时间。配对页上的 6 位 PIN 只用来判断「这是不是配对页」（是不是 6 位数字），数字不保存。

## 安装

```bash
./build.sh
```

需要给 Raycast 辅助功能权限（系统设置 → 隐私与安全性 → 辅助功能）。程序从 Raycast 启动，继承 Raycast 的权限。

界面元素是按 macOS 27 上的「密码」菜单栏窗口结构写的。系统更新改了结构的话，可能需要调整。
