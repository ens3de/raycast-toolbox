# 打开密码菜单

用 Raycast 打开 macOS「密码」App 的菜单栏窗口（`com.apple.Passwords.MenuBarExtra`），并在窗口开着时加上这些快捷键：

| 页面 | 按键 | 作用 |
|---|---|---|
| 列表 | ⌘1 … ⌘9 | 打开当前可见的第 N 项 |
| 列表 | 回车（焦点在搜索框） | 打开第一项 |
| 详情 | ⌘1 / ⌘2 | 复制用户名 / 密码，并收起窗口（停在这一页，方便接着复制另一个） |
| 详情 | Esc | 返回上一页，回到首页时焦点回到搜索框 |
| 首页 | Esc | 照常关闭窗口 |

另外，距上次打开超过 5 分钟（`resetAfter`），再打开时会自动回到首页并聚焦搜索框。

## 原理

- 通过辅助功能（Accessibility）找到菜单栏图标，模拟点击打开窗口，然后把鼠标放回原处。
- 打开后，程序以 `--keys` 在后台再启动一份自己，用 CGEventTap 只拦截上表这几个键，其余按键原样放行。窗口一关它就退出（最长 1 小时），同一时间只会有一个。
- 打开某一项、复制用户名或密码，都是在对应位置模拟一次点击，用的是「密码」自己的行为（它点击即复制）。程序不读取、不记录账号或密码，也不写任何日志。只记录上次打开的时间，存在 `~/Library/Caches/open-passwords-menu.last-run`。

## 安装

```bash
./build.sh
```

需要给 Raycast 辅助功能权限（系统设置 → 隐私与安全性 → 辅助功能）。程序从 Raycast 启动，继承 Raycast 的权限。

界面元素是按 macOS 27 上的「密码」菜单栏窗口结构写的。系统更新改了结构的话，可能需要调整。
